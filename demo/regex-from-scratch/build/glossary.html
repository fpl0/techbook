Glossary

Every term the book introduces, in alphabetical order, with the chapter that defines it.

abstract syntax tree
the tree a pattern parses into, one node per construct with its operands as children and no record of the parentheses ch. 2
backtracking
a search strategy in which each choice point keeps its untried alternatives and a failure returns control to the nearest one that still has some ch. 1
catastrophic backtracking
the failing case of a backtracking matcher whose cost grows exponentially with the input ch. 1
continuation style
this book's name for compiling each node with the state that follows it already in hand, so that no arrow is ever left dangling ch. 2
differential testing
running two implementations on the same inputs and treating every disagreement as a finding to investigate ch. 4
epsilon closure
every state reachable from a given state along split arrows, without consuming a character ch. 3
exhaustive enumeration
generating every input up to a stated size bound rather than a sample of them ch. 4
fragment
a sub-machine with one entry and one exit, produced by compiling one node ch. 2
give back
a star surrendering one character of its run so the rest of the pattern can try again ch. 1
lazy DFA
a DFA whose states are live sets built as the text demands them and kept as a bounded cache that is cleared when full ch. 4
lazy quantifier
a quantifier followed by ?, which in Python matches as few repetitions as it can before letting the rest of the pattern try ch. 4
leftmost-first
the Perl and Python rule for choosing among matches: the earliest start, then the alternative the pattern reaches first ch. 4
leftmost-longest
the POSIX rule: the earliest start, then the longest match from it ch. 4
live set
the set of states the machine occupies before reading the next character, holding only states that can consume a character plus the match state ch. 3
match state
the state with no arrows, whose occupation at the end of the text means the pattern matched ch. 2
match_here
the recursive core of the matcher, which asks only whether the pattern matches at the start of the text ch. 1
Pike VM
Rob Pike's form of the simulation in which each live state is a thread carrying its saved positions, so that captures can be reported ch. 3
polynomial blow-up
the failing case of adjacent quantifiers, whose cost grows as a power of the input equal to the number of quantifiers ch. 1
possessive quantifier
a quantifier followed by +, which in Python 3.11 and later takes as many repetitions as it can and never gives any back ch. 4
precedence level
one row of the operator-binding order, which in a recursive-descent parser is one method ch. 2
recursive descent
a parser made of one function per grammar rule, each calling the rules it depends on ch. 2
simulation
running the machine over the text by advancing every live state together, rather than one path at a time ch. 3
split state
a state with two arrows and no character, which the machine follows both at once ch. 2
star height
the deepest nesting of stars or pluses in a pattern ch. 1
state
a node of the machine, holding at most one character and at most two arrows ch. 2
step
the function from the live set before a character to the live set after it ch. 3
Thompson's construction
the wiring of fragments into a machine with one state per character or metacharacter, from Thompson's 1968 paper ch. 2
unanchored search
matching that may begin at any position, done here by re-entering the start state before every character ch. 3
